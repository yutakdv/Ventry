## 1. 용어 컴플라이언스

`scripts/term_sweep.sh` 로 자동화했다. **단순 grep은 쓸 수 없다** — 도입 시점에 12건을 잡았고
그 전부가 오탐이었다. 규정된 필수 고지 문구("한도·승인은 기관 심사 사항")와 금지 규칙 자체를
설명하는 코드 주석이 걸린 것이다. 오탐이 12건이면 진짜 위반이 섞여도 눈에 띄지 않는다.

허용 패턴은 근거와 함께 스크립트에 적어 두었다. 오탐이 걸러진 뒤 남은 위반은 **0건**이다.

```
$ bash scripts/term_sweep.sh
✅ 위반 없음
```

허용 패턴이 지나치게 넓어 진짜를 놓치는지 반대 방향으로도 검증했다 — 금지어 4종을 심은 파일에
돌려 4건을 모두 잡고, 규정 문구 1줄만 통과시켰다.

## 2. 출처·기준일·추정치 라벨

| 항목 | 상태 |
|---|---|

| 임대료 "한국부동산원 ○○상권 분기 평균(추정)" | ✅ (`lib/format.ts` 단일 통제) |
| 데이터 기준일 | 화면 2·4·탐색·역방향 ✅ / **화면 3(예산 선택)은 아래 참조** |

**화면 1(자금 진단)에는 고지 문구를 넣지 않기로 했다.** 입력 폼이며 자금 상품·금액 정보를
표시하지 않아 고지 대상이 아니다. 모든 화면에 깔면 정작 필요한 화면에서 문구가 묻힌다.

### 화면 3 데이터 기준일 — 계약 한계

`POST /budget` 응답에 `data_as_of` 가 없다(계약 §3). 이 화면은 프리뷰로 환산임대료·유동인구를
보여주는데 기준일의 원천이 없다. **화면이 날짜를 지어낼 수는 없으므로** 출처와 추정 여부만
밝히고 기준일은 다음 화면에 위임했다.

> 위 임대료·유동인구는 공개 조사 기반 추정치이며 데이터 기준일은 입지 추천 화면에 표기됩니다.

**팀 제안**: `BudgetResponse` 에 `data_as_of` 1필드를 추가하면 이 화면도 다른 화면과 같은 수준이
된다. 계약 변경이라 3인 합의가 필요하다.

## 3. 목 자동 폴백 고지 (신규)

`client.ts` 는 실제 호출이 실패하면 조용히 목으로 넘어간다(데모 무중단). 문제는 **화면이 그
사실을 말하지 않는다**는 점이었다. 목 응답에도 "한국부동산원 ○○상권 분기 평균", "데이터 기준일
2026-Q1" 표기가 그대로 붙으므로, 서버가 죽은 채 심사가 진행되면 지어낸 수치를 실데이터로 믿고
보게 된다. 출처를 사칭하는 셈이라 불변 원칙 4와 정면으로 어긋난다.

폴백이 일어나면 셸 상단에 고지를 세운다.

> ⚠ 서버에 연결하지 못해 **예시 데이터**로 표시하고 있습니다. 화면의 수치와 출처·기준일 표기는
> 실제 조사 결과가 아닙니다.

- **실제로 목이 대체하는 6곳에만** 표시를 세운다. SSE 이벤트 파싱 실패는 목 대체가 아니므로 제외했다.
- **한 번 서면 되돌리지 않는다.** 뒤 호출이 성공해도 화면에 이미 목 수치가 섞여 있을 수 있어,
  지우면 그 화면이 다시 실데이터인 것처럼 보인다.
- `VITE_USE_MOCK=1` 에서는 세우지 않는다 — 개발자가 의도적으로 켠 모드는 장애가 아니다.

확인: `docker compose stop api` → 화면 새로고침 → 고지 표시 → `docker compose start api`

## 4. 스타일링 통일

### Pill 여백 — 10종 → 3단

칩·배지 여백을 화면마다 손으로 맞추다 보니 `1px 7px`·`2px 6px`·`2px 8px`·`3px 8px`·`3px 10px`·
`4px 10px`·`5px 12px` 등 10종으로 갈라져 있었다. 같은 성격의 요소가 화면을 옮길 때마다 미세하게
달라지면 완성도로 읽히지 않는다. `tokens.css` 에 3단을 정의하고 10개 클래스를 옮겼다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--pill-pad-sm` | `2px 8px` | 비대화형 소형 태그 (출처·타입·상태 표식) |
| `--pill-pad-md` | `3px 10px` | 상태 배지 (파싱 출처·관심사) |
| `--pill-pad-lg` | `5px 12px` | 누르는 칩 (필터 — 탭 영역이 필요하다) |

`VerdictBadge` 와 지도 말풍선 배지는 **고정 높이 + 좌우 여백만** 주는 다른 패턴이라 옮기지 않았다.

### 모션 축소 요청 대응

`transition` 을 쓰는 모듈 **8개가 `prefers-reduced-motion` 을 갖고 있지 않았다.** 컴포넌트가 늘 때마다
각자 챙기는 방식은 반드시 빠지므로 `global.css` 에서 전역으로 껐다. 지속시간을 0이 아닌 `0.01ms`
로 둔 것은 의도적이다 — 정확히 0이면 `transitionend` 가 발화하지 않는 브라우저가 있다.

CSS 미디어 쿼리는 **JS가 부르는 애니메이션에 닿지 않는다.** 목록 자동 스크롤
(`scrollIntoView({ behavior: 'smooth' })`)은 `lib/motion.ts` 로 호출 지점에서 확인한다.
