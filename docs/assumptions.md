# assumptions.md — 가정·폴백 일원화 대장

모든 배치 산출·계산의 가정은 발생 즉시 이 문서에 등재한다 (스펙 §2-2).
등재 형식: 날짜 / 담당 / 가정 내용 / 근거 / 영향 범위.

### 채번 규칙 (하드 룰)

- 번호는 **파트 무관 단일 시퀀스**다. AI·BE·FE·CM이 같은 번호대를 각자 쓰지 않는다.
- 새 항목은 **표의 마지막 번호 + 1**. 표는 번호 오름차순으로 유지한다.
- 두 파트가 동시에 작업해 같은 번호를 잡았다면, **나중에 병합되는 쪽이 재채번**한다
  (선점은 등재 날짜 기준). 재채번 시 리포 안의 상호참조를 같은 커밋에서 함께 옮긴다.
