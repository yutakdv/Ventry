# 프로젝트 원칙과 용어 규정

Ventry — 여금(여유 자금) 우선 입지 컨설팅 에이전트.
KB 제8회 Future Finance AI Challenge · 주제 2 「AI 데이터 기반 최적 입지 컨설팅 서비스」.

"어디가 좋은가"가 아니라 **"내 한도로 어디까지 가능한가"** 를 답하는 서비스다.
스코프: 서울 / 카페·음식점.

이 문서는 코드 주석이 근거로 인용하는 **불변 원칙과 용어 규정의 정본**이다.
설계 전반은 `docs/specs/최종_스펙문서.md`, API 계약은 `docs/API_CONTRACT.md` 가 기준이며,
문서와 코드가 어긋나면 스펙 문서가 우선한다.

---

## 1. 절대 불변 원칙 (스펙 §0-1, §1)

1. **모든 숫자는 결정적 계산이 만든다.** LLM은 (a) 탐색 축 우선순위 계획, (b) 구조화 결과의
   언어화, (c) 리스크 검증 반박문 생성만 담당한다. LLM의 수치 생성·재계산은 금지다.
2. **서빙 경로에 ML 모델이 없다.** LightGBM+SHAP은 오프라인 배치 검증(§12) 전용이며,
   `lightgbm`·`shap` 의존성은 `ai/` 배치 requirements에만 존재한다.
3. **좌표는 전부 WGS84** (프론트 계약), 금액은 **만원 단위 정수**, 데이터 기준일은 상시 표기한다.

## 2. 용어 컴플라이언스

- 판정 4단계: `적합 / 조건부 적합 / 유의 / 범위 외` — "승인" 계열 단어는 쓰지 않는다.
  API enum은 `FIT / CONDITIONAL / CAUTION / OUT_OF_SCOPE`.
- "심사역" → "리스크 검증".
  "조달 가능" → "자격 요건 부합 상품 확인(한도·승인은 기관 심사 사항)".
- 자금 관련 "권장/추천드립니다"를 쓰지 않는다 → 정보 서술형으로 적는다
  ("~하면 …지표가 개선됩니다").
- 상향 인사이트는 단독으로 노출하지 않는다: 지속 후보 수 + 하향 안전 마진 + 고지 문구를
  반드시 동반한다.
- 고지 문구(정본):
  > 본 정보는 공개 자료 기반 정보 제공이며 대출 권유·중개·자문이 아닙니다.

## 3. 데이터 라벨 규정

- 임대료: **"한국부동산원 ○○상권 분기 평균 (추정)"**
- 권리금: **"연간 조사(전년 기준)"**

두 라벨은 표·캡션·화면 어디에서도 떨어지지 않는다. 해상도와 기준 시점을 숨기지 않기 위한 규정이다.

## 4. 저장소 구조

| 경로 | 내용 | 스택 |
|---|---|---|
| `frontend/` | 화면 | React 18 + Vite + TS, 카카오맵 JS SDK, SSE |
| `backend/` | 서빙 | Spring Boot 4.1 (Java 25) + PostgreSQL + Caffeine, SseEmitter |
| `ai/` | 배치·평가 | Python 3.11 — 수집/전처리(pandas·geopandas)/적재 배치 + 평가 하네스(`make eval`) |
| `db/init/` | 사전 적재 덤프 | compose 최초 기동 시 자동 실행 |
| `docs/` | 스펙·계약·가정 대장·심사 Q&A | — |

## 5. 구현 시 지켜지는 제약

- 결정적 도구 계층(`eligibility_filter` / `cost_calculator` / `score_lookup` / `frontier` /
  `reverse_check`)은 순수 함수이며 단위 테스트를 갖는다 (스펙 §5-1).
- `/explore` SSE는 템플릿 문장을 즉시 송출하고 LLM refine이 선택적으로 교체한다.
  LLM 장애 시 템플릿이 최종본이다 (무중단 원칙, exploration spec §2-5·§5).
- 인용은 검색이지 생성이 아니다: `source_quote`는 `finance_doc_chunk` 원문 그대로이며
  LLM이 재작성하지 않는다 (§5-4). 유사도 검색·벡터DB는 도입하지 않았고,
  `doc_chunk_ref` id로 직접 조회한다.
- 배치 산출물의 모든 가정은 `docs/assumptions.md` 에 즉시 등재한다
  (좌표계·정규화·폴백 규칙 등).
