### 1-1. 대본 수치 사전 점검 (하드 룰)

**대본의 숫자가 화면과 다르면 피험자는 자기가 뭘 잘못했다고 생각하고 멈춘다.** 실제로
배치 재적재(이슈 #152, 업종 대표면적 교정)로 도슨트 수치가 통째로 이동한 적이 있다 —
「예산 8,000만 → 342곳」이 같은 예산에서 **6곳**이 됐다. 측정 전에 반드시 확인한다.

```bash
python3 scripts/qa_integration.py --only D1     # 도슨트 대본 수치 정합
```

이 게이트는 README 도슨트 가이드에 적힌 수치를 기동 중인 스택에서 재현해 대조한다.
**실패하면 피험자를 부르기 전에 README를 먼저 고친다** — 대본이 틀린 채로 측정하면
「가이드가 스스로 작동하는가」가 아니라 「사람이 틀린 숫자를 참고 넘어가는가」를 재게 된다.

현재 대본 기준값 (2026-07-28 실적재본):

| 지점 | 값 |
|---|---|
| 화면 2 보수 / 적극 카드 기본 예산 | 7,901만 / 1억 440만 |
| 화면 3 확정 예산 | **1억** |
| 진입 가능 후보 / 조건부 적합 | 382곳 / 636곳 |
| 상위 후보 | 방이동먹자골목 적합(94) · 잠실역 적합(86) · 을지로입구역 조건부 적합(85) |
| T1 인사이트 | 3,869만 추가 → 진입 382 → 1,014곳 · 지속 안정 244곳 |
| 자격 부합 상품 | 11건 (인용 7건) |

## 2. 진행자가 **말하지 말아야 할 것** (측정 오염 방지)

이 테스트가 재는 것은 "가이드가 스스로 작동하는가"이지 "설명을 들으면 이해하는가"가 아니다.
아래를 말하는 순간 그 회차의 데이터는 버려야 한다.

- ❌ "저기 카드를 눌러보세요" 등 **다음 행동 지시**
- ❌ "T1이 핵심이에요" 등 **주목 지점 안내**
- ❌ "진입은 늘고 지속은 준다는 뜻이에요" 등 **개념 해설**
- ❌ 용어 풀이("여금이란…", "프론티어란…")
- ⭕ 허용: "화면에 보이는 대로 하시면 됩니다", "막히시면 그대로 두세요" (무정보 응답)
- ⭕ 허용: 기술적 장애 대응(서버 다운·새로고침) — 단 그 시간은 타이머에서 제외

## 3. 통과 조건 (하나라도 미달이면 실패)

| # | 조건 | 판정 방법 |
|---|---|---|
| 1 | **3분 이내** 화면 3(지도 판정)까지 도달 | 타이머 |
| 2 | **T1 인사이트의 「진입 N곳 / 지속 안정 M곳」 병기를 스스로 읽어냄** | 피험자가 두 숫자를 언급하는가 (유도 없이) |
| 3 | 그 차이의 의미를 **자기 말로** 설명 — "돈을 더 빌리면 갈 수 있는 곳은 늘지만 버티기는 어려워진다" 수준 | 사후 인터뷰 Q1 |
| 4 | "이 서비스가 뭘 해주는 거냐"에 **"내 예산으로 어디까지 가능한지"** 취지로 답함 | 사후 인터뷰 Q2 |

조건 2가 이 테스트의 **핵심**이다. 진입/지속 비단조성이 본 서비스의 은행 관점이며,
심사위원이 여기에 도달하지 못하면 나머지 구현의 가치가 전달되지 않는다.

## 5. 실패 시 조정 순서 (위에서부터)

가장 싼 수정부터 시도한다. 화면 구조 변경은 D10 기능 동결 이후이므로 최후 수단이다.

1. **README 문구** — 단계 번호·굵기·화살표 위치. 가장 싸고 즉시 재테스트 가능
2. **화면 카피** — 카드 제목·배지 문구·툴팁 (FE-06 마감 스윕 범위 안)
3. **동선 순서** — 가이드의 단계 순서를 바꿔 T1을 앞으로 당김
4. **자동 전개 규칙** — 탐색 카드의 세션 최초 1회 자동 펼침 타이밍 (expl §3)

조정 후 **다른 피험자**로 재측정한다. 같은 사람은 이미 학습해서 3분 안에 들어간다.
